# 第一课：用 Python 管理待办清单

练习文件：[lesson01.py](../lesson01.py)。在 VS Code 里保存文件，然后在文件所在目录的终端运行 `python lesson01.py`。VS Code 用来编辑代码，Python 解释器负责执行，终端负责接收输入、显示输出。

## 跟着一条新任务读代码

1. `tasks = ["学习Python", "完成Todo项目"]` 创建一个列表。引号里的文字叫字符串；`=` 表示赋值，以后用 `tasks` 这个名字就能找到整张清单。
2. `new_task = input("请输入任务；")` 会显示引号里的提示并等待输入。假如输入“复习单词”再按回车，`new_task` 的值就是这段文字。此时列表仍然只有两项。
3. `tasks.append(new_task)` 把这段文字加到列表末尾。点号前的 `tasks` 指定要修改哪张清单，圆括号里放要添加的内容。现在列表有三项。
4. `for task in tasks:` 按顺序取出每一项。`task` 是自己取的变量名，每一轮代表当前这一项。
5. `print(task)` 前面的四个空格表示它属于循环。每轮显示一项，所以三条任务分三行输出。单独写 `print(tasks)` 则会一次显示整个列表。

## 为什么用方括号？

`["A", "B"]` 是列表，保留顺序，允许重复，用 `append()` 添加任务。`{"A", "B"}` 是集合，会去重，不保证按写入顺序显示，用 `add()` 添加元素。两者都能遍历，列表适合按添加顺序显示的待办清单。

## 今晚遇到的报错

- `Missing parentheses in call to 'print'`：调用函数需要英文圆括号，把 `print{tasks}` 改成 `print(tasks)`。
- `SyntaxError: expected ':'`：循环头末尾要写英文冒号 `:`，下一行循环体要缩进。
- 读报错时先看最后一行的原因，再往上找自己的文件名和行号。调试时如果停在断点，可以按 F10 单步执行并观察 `task` 的值。

## 自测

输入“复习单词”后，如果跳过 `append()`，最后会打印几条任务？答案是两条：`input()` 只把文字交给 `new_task`，`append()` 才会修改列表。重新运行程序时，列表会按第一行重新创建。
